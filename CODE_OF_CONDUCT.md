# Contributor Covenant Code of Conduct

## Our Pledge

We are committed to maintaining a professional, respectful and technically constructive community around `KUKULCAN.SharedKernel.Example`.

We aim to provide an inclusive environment where contributors can collaborate on the Example application, discuss architectural decisions, improve integration patterns and share technical knowledge without fear of harassment or discrimination.

## Our Standards

Expected behavior includes:

- Respectful technical discussion and constructive criticism.
- Clear communication about design decisions, architectural trade-offs and implementation alternatives.
- Respect for different levels of experience, technical backgrounds and perspectives.
- Collaboration focused on improving code quality, application behavior, security and maintainability.
- Willingness to explain technical decisions and consider evidence-based alternatives.
- Respect for project guidelines, contribution procedures and the responsibilities of the KUKULCAN shared libraries.
- Constructive feedback on code, tests, documentation, API contracts and integration approaches.

Unacceptable behavior includes:

- Harassment, personal attacks, discrimination or threats.
- Deliberately disruptive conduct or repeated interference with constructive technical discussions.
- Publishing private information without permission.
- Abusive, insulting or demeaning language directed at contributors.
- Deliberately misleading contributors about technical decisions, project requirements or test results.
- Any other conduct considered inappropriate in a professional collaborative environment.

## Scope

This Code of Conduct applies to all project-related spaces and activities, including:

- The `KUKULCAN.SharedKernel.Example` repository.
- GitHub Issues and Discussions.
- Pull requests, code reviews and commit discussions.
- Project documentation and contribution-related communication.
- Other online or offline spaces where individuals represent the project or its community.

All contributors, maintainers and participants are expected to follow these standards.

## Reporting

Contact project maintainers privately to report conduct concerns. Reports should include relevant details and, where possible, supporting evidence.

Reports will be reviewed with appropriate discretion. Maintainers should handle concerns fairly and take reasonable steps to protect the privacy of those involved.

Security vulnerabilities must be reported according to `SECURITY.md`, not through public Issues or Discussions.

## Enforcement

Maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the severity and circumstances of a violation, proportionate action may include:

- A request to correct the behavior.
- A formal warning.
- Temporary restrictions on participation.
- Removal of inappropriate content or contributions.
- Temporary suspension or permanent exclusion from project spaces.

Enforcement decisions should consider the nature, severity and recurrence of the conduct, with the objective of maintaining a safe, respectful and productive community.
