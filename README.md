# KUKULCAN.SharedKernel.Example

Reference ASP.NET Core Web application demonstrating how the KUKULCAN.SharedKernel ecosystem can be consumed from a real application.

## Purpose

This repository is the integration example for:

- KUKULCAN.SharedKernel
- KUKULCAN.SharedKernel.Auth
- KUKULCAN.SharedKernel.Database
- KUKULCAN.SharedKernel.I18n
- KUKULCAN.SharedKernel.JsonEngine

The application will consume the published NuGet packages and will progressively demonstrate their integration.

## Status

The repository is currently establishing its base Web application structure. Functional examples will be introduced through the project's TDD workflow.

## Structure

- `Source/` - production application
- `Tests/` - automated tests
- `Documentation/` - architecture and usage documentation
- `.github/workflows/` - continuous integration

## Target Framework

.NET 10.
